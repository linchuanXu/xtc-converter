# 怎么用好 XT 书籍转换器

这里不讲一堆参数，只讲：**你手里是哪种书，想达到什么效果，该怎么设**。右边预览就是最终效果，多翻几页、调一调，看到顺眼再导出就行。

---

## 我主要是看小说（纯文字）

- **直接干**：拖进 EPUB/MOBI/TXT，选一个文字预设（**大字版 / 舒适版 / 便携版**），看预览顺眼就点「导出全书」。
- 想翻页快、能接受锯齿：选 **快速刷新**（1-bit），快刷、有锯齿。
- 想要无锯齿、层次好：选 **高清**（2-bit），灰度、会闪屏、无锯齿。
- **抖动**保持默认「智能识别图片」即可；纯文字页不会乱抖，字会保持清晰。
- 字体在左侧选，有思源黑体/宋体、霞鹜文楷等；想用自己字体就选「★ 自定义字体」上传 TTF/OTF。

---

## 书里有图也有字（图文混排）

这种书一般是：一段文字 + 几张插图，或者图嵌在段落里。

**推荐做法：**

1. **输出质量**选 **高清**，这样插图的层次会好很多。
2. **抖动**用默认的 **「智能识别图片抖动」**：  
   软件会尽量只对「图」做抖动，字保持清晰。你翻几页看，字糊了就把下面一步调一下。
3. 如果发现**图没被认出来**（整页灰灰的没层次）、或者**字被当成图抖了**（字发糊）：  
   点顶上的 **专家**，在「图像」里找到 **「识别敏感度」**：  
   - 图经常没被识别 → 把敏感度**调高**一点（更多区域会被当图来抖）；  
   - 字被误伤 → 把敏感度**调低**一点（只有明显是图的地方才抖）。
4. 插图发灰、不够黑或太白：在专家模式里展开 **「图片区域（黑白转换）」**，单独调**图片区域**的**亮度、对比度、抖动强度**，文字不会跟着变。
5. 图片预设可以试试：**均衡**（默认）、**照片感**（图更柔和）、**线稿感**（线条更利落），看你这本书的图更适合哪种。

**小结**：图文混排就靠「高清 + 智能识别图片抖动」，再根据预览微调敏感度和图片区域的亮度/对比度。

---

## 我主要是看漫画（或整页都是图）

漫画、画册、扫描版 PDF 之类，一页就是一整张图，你要的是：**画面铺满、少白边、层次清楚**。

**推荐做法：**

1. **输出质量**选 **高清**（2-bit），否则线条容易糊。
2. **边距**：  
   - 图多的 EPUB 拖进来后，边距会自动变成 0，你可以从 0 开始调。  
   - 如果四周还有白边，到**专家**里把**边距**调成**负数**，比如 **-8 ～ -20**（上/下/左/右可以分开设），相当于把白边裁掉，画面更满。
3. **图片缩放**：在专家 → 图像里有个 **「图片缩放」**（80%～180%）。  
   - 图太小就调大一点（例如 110%～120%）；  
   - 图太大被裁了就往回调一点。  
   和边距一起用，调到预览里看着舒服为止。
4. **抖动**可以两种都试试：  
   - **「智能识别图片」**：一般够用，字（如果有）不会糊。  
   - **「全页抖动」**：整页都做抖动，适合整页是图、没有大块文字的情况，层次会更均匀。
5. 画面偏灰、线条不清晰：在 **「图片区域」** 里调**对比度**、**抖动强度**；线稿风漫画可以试试图像预设里的 **「线稿感」**。

**小结**：漫画 = 高清 + 负边距裁白边 + 图片缩放填满屏 + 全页抖动或智能识别，再按观感微调对比度/抖动。

---

## 我的是 PDF（扫描书、论文、漫画 PDF）

PDF 是整页整页渲染的，和 EPUB 不太一样。

- **抖动**：PDF 一般用 **「全页抖动」** 更合适（在专家 → 图像里选）。  
  因为整页都是一张图，没有「字」和「图」分开识别的问题。
- **质量**：想要清楚、无锯齿就选 **高清**（2-bit，会闪屏）；能接受锯齿、要快刷就选 **快速刷新**（1-bit）。
- 同样可以调**边距**（含负边距）和 **图片缩放**，把版面裁成你要的样子。
- 亮度、对比度在专家 → 图像里调，对整页都生效。

---

## 画面发灰、不够干净怎么办？

- **纯文字页**：把抖动改成 **「不抖动」**，字最干净，没有任何灰度。
- **图+字**：用 **「智能识别图片」**，只对图抖、字不抖；若字还是糊，把 **识别敏感度** 调低。
- **整页是图**：用 **「全页抖动」**，再在 **「图片区域」** 里调**抖动强度**：强度太大容易糊，可以适当降一点；同时调**对比度**让黑白更分明。

---

## 想显示「读到第几页、进度多少」

在**专家**模式里，找到 **「进度条」** 那一块，勾选 **启用**，然后选：

- 放在**顶部**还是**底部**；
- 要显示哪些：书籍进度条、章节标记、页码（X/Y）、百分比等；
- 进度条样式（线条 / 条形）、字号、边距、颜色。

调完看预览，每页顶部或底部就会出现进度信息，导出后设备上也会一样。

---

## 几个实用小技巧

- **先看几页再导出**：用「上一页 / 下一页」和「跳转」多翻几页，尤其看看有图的、有表格的页，确认没问题再导出全书。
- **配置存下来**：调好一套参数后，用 **「导出配置」** 存成 JSON，下次同类型的书用 **「导入配置」** 就能复用。
- **单页调试**：不确定某一页效果时，可以用 **「导出当前页」** 导出一张 XTG/XTH 到设备上看，再回来改设置。
- **传输时间**：导出时会提示文件大小和「星曈云大概要传多久」「U 盘大概要多久」，方便你选 XTCZ 还是 XTC/XTCH。

## 一句话对照

| 你的情况           | 建议 |
|--------------------|------|
| 纯文字小说         | 快速刷新 + 舒适/大字/便携预设，抖动默认即可 |
| 有插图的文学书     | 高清 + 智能识别图片抖动，图糊就调「图片区域」亮度对比度 |
| 漫画 / 画册        | 高清 + 负边距 + 图片缩放 + 全页抖动或智能识别，再调对比度 |
| PDF 扫描/漫画      | 高清 + 全页抖动 + 边距/缩放按需调 |
| 字被抖糊了         | 识别敏感度调低，或改用「不抖动」（纯文字时） |
| 图灰、层次不够     | 图片区域对比度/抖动强度调高，或试「线稿感」预设 |
| 白边太多           | 专家里边距调成负数（如 -10），配合图片缩放 |

按你的书类型对上表，再结合预览微调，就能又快又省心地导出到 Xteink 上看了。
