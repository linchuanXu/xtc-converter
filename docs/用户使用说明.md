# XT 书籍转换器 — 用户使用说明

将 EPUB、PDF、MOBI、TXT、Markdown、DOC/DOCX 等电子书转换为 Xteink 电纸书（X3/X4 等）可用的 **XTC/XTCH** 格式。**预览即导出效果**，所见即所得。

---

## 一、适用设备与格式

### 支持的阅读器

| 设备 | 屏幕分辨率 | 说明 |
|------|------------|------|
| **Xteink X4** | 480×800 | 4.3 寸屏，默认预设 |
| **Xteink X3** | 528×792 | 可选预设 |
| **自定义** | 任意宽高 | 专家模式中可输入自定义尺寸 |

### 支持的输入格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| **EPUB** | `.epub` | 标准电子书，支持目录、图文混排 |
| **PDF** | `.pdf` | 由 PDF.js 渲染，分页与预览一致 |
| **MOBI** | `.mobi`、`.azw`、`.prc`、`.pdb` | Kindle 等常见格式 |
| **纯文本** | `.txt` | 由 CREngine 解析排版 |
| **Markdown** | `.md`、`.markdown` | 转为 HTML 后排版 |
| **Word** | `.doc`、`.docx`、`.docm` | 由 CREngine 解析 |

### 输出格式

| 格式 | 扩展名 | 特点 |
|------|--------|------|
| **XTC** | `.xtc` | 1-bit 快刷，有锯齿，体积小，适合纯文字 |
| **XTCH** | `.xtch` | 2-bit 灰度，闪屏、无锯齿，画质更好，适合漫画/图片 |
| **XTCZ** | `.xtcz` | 使用 LZ4 压缩的 XTC/XTCH，体积更小，适合星曈云等传输 |

导出时可选择「快速刷新」（1-bit）或「高清」（2-bit），以及「XTCZ (LZ4)」或「XTC/XTCH」容器格式。

## 二、界面与模式

### 简洁 / 专家模式

- **简洁模式**：只显示最常用选项（文件、输出质量、预设、字体、章节、导出）。适合快速选书、选预设、导出。
- **专家模式**：展开全部设置，包括：
  - **文本**：字号、字重、行高、边距（含四边独立）、段首缩进、段间距、对齐、连字与语言
  - **设备**：设备预设、自定义尺寸、旋转（0°/90°/180°/270°）、横屏单/双栏、缩放说明
  - **图像**：导出格式、亮度/对比度、图片缩放、抖动模式与强度、反相（暗色模式）、图片区域单独调节
  - **进度条**：是否显示、位置、主题、书籍/章节进度、页码、百分比、字体与边距等

顶栏可切换「简洁」与「专家」，并支持**中/英**语言切换。

### 输出质量（两个大按钮）

- **快速刷新**：1-bit（XTC），快刷、有锯齿，小字可能不清晰，不适合漫画；体积小。
- **高清（闪屏）**：2-bit（XTCH），灰度、闪屏、无锯齿，画质更好，适合漫画/图片。

### 预设

- **文字预设**：大字版 / 舒适版 / 便携版 — 一键调节字号、行高、边距等，适合不同阅读习惯。
- **图像预设**：均衡 / 照片感 / 线稿感 — 影响图片区域的亮度、对比度、抖动强度等，适合纯文字、摄影图、漫画线稿等不同内容。

## 三、主要功能说明

### 1. 文件与预览

- **拖放或点击**：将 EPUB、PDF、MOBI、TXT、MD、DOC/DOCX 拖入或选择文件。
- **预览区**：右侧为当前页的 Canvas 预览，与导出的页面一致。
- **翻页**：上一页 / 下一页、刷新当前页、**跳转到指定页**（弹窗输入页码）。
- **章节列表**：左侧可展开「章节」，点击跳转到对应章节首页。
- **导出单页**：可将当前页导出为单页 `.xtg`（1-bit）或 `.xth`（2-bit），用于调试或单页使用。
- **导出全书**：生成整本书的 XTC/XTCH 或 XTCZ 文件，并显示文件大小、星曈云/U 盘传输预估时间，确认后下载。

### 2. 字体

- **预设字体**：思源黑体/宋体、霞鹜文楷、MiSans、Alegreya、Literata、Lora、Noto 系列等（中英混排或纯英）。
- **自定义字体**：选择「★ 自定义字体」后上传 **TTF/OTF** 文件，用于全书渲染与导出。
- 字体在简洁模式下也可切换，专家模式下可调字重。

### 3. 背景图

- **选择背景图**：可为页面指定一张背景图（如纸张纹理），与正文内容叠加显示并参与导出。
- **官方默认**：一键恢复为内置默认背景图。
- **显示模式**：拉伸或平铺（专家模式下可选）。
- **背景单独调节**：亮度、对比度、背景区域是否抖动等，仅作用于背景图，不影响正文。
- 背景在「阅读下划线」上方合成，可与下划线、进度条等同时使用。

### 4. 阅读下划线

- 为文本中的「下划线」（`text-decoration: underline`）绘制可见下划线样式。
- 可选多种线型（虚线/实线、明显/柔和等）以及**位置偏移**（相对基线的上下），便于与字体协调。
- 下划线在导出时与正文、背景图、进度条一起合成到最终页面。

### 5. 进度条（状态栏）

- 在每页顶部或底部绘制**阅读进度**信息（专家模式中开启）。
- 可显示：**书籍进度**（进度条/百分比）、**章节标记**、**章节内进度**、**页码 X/Y**、**书籍百分比**、**章节 X/Y**、**章节百分比**等。
- 可调：位置（顶/底）、主题（线条/条形）、状态栏字体大小、上下边距、左右边距、颜色（黑/深灰/中灰/浅灰）。
- 可选「显示原生标题/页码」与 CREngine 自带页眉配合使用。

### 6. 图像与抖动

- **抖动模式**：
  - **不抖动**：适合纯文字页，无灰度过渡。
  - **仅图片区域抖动**（默认）：智能识别图片区域，只对图片做抖动，文字保持清晰，适合图文混排。
  - **全页抖动**：整页统一抖动，适合整页是图或漫画。
- **识别敏感度**：在「仅图片区域」下可调节识别强弱（敏感度高则更多区域被视为图片）。
- **图像区域单独设置**：对识别出的图片区域单独调节亮度、对比度、抖动强度、反相，文字不受影响。
- **全页**：亮度、对比度、图片缩放（80%–180%）、反相（暗色模式）。
- **图片缩放**：以页面中心为基准缩放整页内容，适合漫画或图多的书。

### 7. 漫画与图多的书

- 图多的 EPUB 加载后，边距会自动设为 0，便于从 0 开始微调。
- 建议尝试**负边距**（如 -8 ～ -20）裁掉白边，使画面更满。
- 配合**图片缩放**与**边距**（专家模式可调四边）直到预览满意再导出。
- 可选用「高清」+「仅图片区域抖动」或「全页抖动」视内容而定。

### 8. 配置导入 / 导出

- **导出配置**：将当前设备的尺寸、字体、边距、质量、抖动、进度条等设置导出为 JSON 文件。
- **导入配置**：从 JSON 恢复上述设置，便于在多台设备或不同书籍间复用同一套参数。

## 四、基本使用流程

1. **打开页面**：在浏览器中打开本应用（或自托管后的地址）。
2. **选择文件**：点击或拖入一本 EPUB、PDF、MOBI、TXT、MD 或 DOC/DOCX。
3. **等待加载**：引擎加载并分页，第一页出现在预览区。
4. **选择设备**：在「设备」里选 Xteink X4 或 X3（或自定义尺寸），使页面尺寸与阅读器一致。
5. **选预设（可选）**：点「大字版 / 舒适版 / 便携版」和图像预设，快速定型。
6. **细调（可选）**：切换到「专家」模式，调整字体、边距、抖动、进度条等。
7. **预览**：翻几页确认效果，可用章节列表或「跳转」到指定页。
8. **导出**：点击「导出全书」，选择 XTCZ 或 XTC/XTCH，确认文件大小与传输时间后下载。
9. **传到设备**：将下载的 `.xtc` / `.xtch` / `.xtcz` 通过星曈云或 U 盘拷贝到 Xteink 设备即可阅读。

---

## 五、导出与传输

- **导出全书**：生成一个包含全书所有页面的 XTC/XTCH 或 XTCZ 文件，并弹出确认框显示：
  - 文件大小；
  - 通过星曈云传输的预估时间（约 180 KB/s）；
  - 通过 SD 卡插 U 盘传输的预估时间（约 25 MB/s）。
- **导出单页**：仅导出当前页为 `.xtg` 或 `.xth`，用于测试或单页使用。
- 导出前可切换「快速刷新」/「高清」和「XTCZ (LZ4)」/「XTC/XTCH」，导出结果与当前预览一致。

## 七、常见问题简表

| 问题 | 建议 |
|------|------|
| 预览/导出空白或报错 | 确认文件未损坏、格式在支持列表中；尝试换一本或换浏览器。 |
| 字体显示不对 | 检查是否选了「自定义」但未上传字体，或上传的 TTF/OTF 是否完整；可先选预设字体测试。 |
| 图片发灰、不清晰 | 尝试「不抖动」或「仅图片区域抖动」并调「识别敏感度」；图多时可试「全页抖动」。 |
| 漫画白边太多 | 使用负边距（专家模式可调四边）并配合「图片缩放」。 |
| 想保留阅读进度 | 在专家模式中开启「进度条」，选择位置与要显示的项目（书籍%、页码、章节等）。 |
| 文件太大、传输慢 | 导出时选「XTCZ (LZ4)」可减小体积；纯文字可优先用「快速刷新」(1-bit)。 |
